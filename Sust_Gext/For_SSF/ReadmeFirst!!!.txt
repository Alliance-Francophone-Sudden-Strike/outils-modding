     NEW!!!               "Viewer and Extractor for SUDDEN STRIKE FOREVER    ver.1.03 eng.   10.10.2003

INTRODUCING.

This tool was created for external use for "extracting" graphics from schemes resources files…
This program based on qed.exe editor.

THE INSTRUCTION ON INSTALLATION 
To unpack archive with the extractor in same catalogue with qed.exe.
Total three files:
Ext.exe
Extr.sue
G-extr2.ini

 Further...
Start the utility ext.exe 




USES


After start of the program will appear modified qed windows…
We can select any graphics clicking  menu icons or from TOOLS window….
We can select DEMANGE for building…est.…

Use <  |  ^  |  >  |  v keys for strong scrolling...
We can delete not needed graphics by eraser…
In this version added menu "Load map" and "Save map" for saving work...
!!!For saving first you need click "Activate scheme" (Menu button)..
Saving picture by two ways: 

1.	Capture by PrintScreen Hotkey
                  or

2.	Generate bitmap (Menu button) - this way is useful if you want extract many graphics for next cutting..
          But file size is a.90 MB!

For use with mods we must edit G-extr2.ini:
Insert for each scheme text from editor2.ini
Place marked by puncture lines!
Or add 
DataDir#=Extr.sue  
# - number of last directory...

.ini file is based on original english SSF...
 If you have problem with initialisation - send me your editor2.ini file to WildCat@freemail.dnepr.net !
