     NEW!!!               "Viewer and Extractor for SUDDEN STRIKE II    ver.1.06 eng.   10.10.2003

INTRODUCING.

This tool was created for external use for "extracting" graphics from schemes resources files…
This program based on edit3.exe editor.

THE INSTRUCTION ON INSTALLATION 
To unpack archive with the extractor in same catalogue with edit3.exe.
Total three files:
Extr3.exe
Extr.sue
Extr3.ini

 Further...
Start the utility extr3.exe 




USES


After start of the program will appear modified edit3 windows…
We can select any graphics clicking  menu icons or from TOOLS window….
We can select DEMANGE for building…est.…
Use F3 hotkey for viewing workplace and for line placement of graphics…
Use <  |  ^  |  >  |  v keys for strong scroling...
We can delete not needed graphics by eraser…
In this version added menu "Load map" and "Save map" for saving work...
Saving picture by two ways: 

1.	Capture by PrintScreen Hotkey
                  or

2.	Generate bitmap (Menu button) - this way is useful if you want extract many graphics for next cutting..
          But file size is a.90 MB!

For use with mods we must edit extr3.ini:
Insert for each scheme text from edit3.ini
Place marked by puncture lines!
Or add 
DataDir#=Extr.sue  
# - number of last directory...

.ini file is based on original german SS2...
 If you have problem with initialisation - send me your edit3.ini file to WildCat@freemail.dnepr.net !
